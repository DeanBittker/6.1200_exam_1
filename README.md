# 6.1200 Quiz 1 Prep

A study site for MIT 6.1200 Quiz 1 (Wed Oct 14, 2026), built from Lectures 1–9, Recitations 1–9 and Problem Sets 1–4.

**Open `index.html` in any browser.** There's nothing to install. Progress, checklists and chalkboard drawings are saved in your browser's local storage.

## What's inside
- **Notes**: 10 topics, each with the big idea, must-know facts, a step-by-step procedure, a worked example, common traps, the related practice problems and an "I can…" checklist.
- **Practice**: 89 problems from lectures, recitations and PSets 1–4, plus some original ones. Each has a chalkboard, timed hints, and a solution that stays locked until you've spent time on it and shown an attempt.
- **Study plan**: a day-by-day plan for Oct 9–14 with a redo list built from your self-ratings.
- **Formula sheet** and **mock quiz** (6 problems, 2-hour timer).

PSET 5 is intentionally not included: it's an active problem set and the course doesn't allow AI help on problem sets.

## Editing
Content lives in `src/` (`topics.html`, `problems-a.html`, `problems-b.html`, `shell.html`, `app.js`). Run `python3 build.py` to regenerate `index.html` and `site.html`.
